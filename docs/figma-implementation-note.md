# Figma implementation

This implementation intentionally starts from the current Figma Make sketch as the visual baseline. The next pass should refine spacing, typography, colors, and responsive details against the Figma reference without expanding product scope.

## Current baseline
- React + Vite + Tailwind
- City service administration context
- Use existing UI components where available
- Preserve current product structure and terminology

## Implementation order
1. Match page structure from Figma sketch.
2. Match typography, spacing, borders, radius, and interaction states.
3. Validate the page at mobile viewport sizes.
4. Compare against Figma and refine visual differences.
