# Validation Case — Current Project

## Purpose

Use the current department-registration project as the first real consumer of the packaged AI Native Project OS.

## Scope

Validate that the package can resume an existing project context and route stages without requiring the user to restate prior decisions.

## Cases

1. `继续 Design` — verify Design context, component specifications and Figma/design outputs are discovered.
2. `继续 Coding` — verify Product + Design outputs are consumed without redefining them.
3. `启动 Preview` — verify Build / Deploy / Preview handoff.
4. `启动 Acceptance` — verify Product and Design acceptance criteria.
5. `启动 QA` — verify test and issue loop.
6. `启动 Release` — verify release gate and human approval behavior.
7. `启动 Data` — verify conditional SKIPPED behavior when no experiment is required.
8. `复盘 Review` — verify evidence-based retrospective.
9. `更新 Knowledge` — verify knowledge deduplication and Evolution update.

## Expected result

The plugin must preserve current project decisions, avoid redundant questions, maintain Stage Status and produce traceable Handoff and Evolution artifacts.
