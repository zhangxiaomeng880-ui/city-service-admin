# V2.0 Resource Pool — V1.0 Asset Migration

## 1. Migration purpose

本次迁移用于 V2.0 Validation：以 V1.0 已完成的真实项目资产作为验证样本，将现有资产复制进入 V2.0 Resource Pool，验证 V2.0 Resource / Capability / Command / Runtime / Routing / Execution / Audit 能力是否可以直接作用于真实历史资产。

## 2. Preservation rule

- V1.0 原始资产不修改、不删除、不覆盖。
- V2.0 使用独立 Resource Pool 副本作为验证资产。
- V2.0 验证过程中产生的新版本、映射、验证记录和问题记录不回写 V1.0。
- V1.0 仍然作为历史事实源和原始执行证据。

`ai/knowledge-base/v2.0/resource-pool/v1.0/`

## 5. Validation usage

V2.0 验证阶段统一优先从 `resource-pool/v1.0` 读取验证样本，并建立：

`V1.0 Source → V2.0 Resource → Capability → Command → Runtime → Execution → Audit → Trace`

验证重点：

1. 资源是否可以被标准 Resource Contract 描述。
2. 资源是否可以被 Query / Retrieval / Context Assembly 查询和组装。
3. 已有资源是否可以通过 Command 主动调用。
4. Model / Tool / MCP / Skill / Agent 是否可以作用于资源。
5. Routing 是否可以选择执行路径。
6. 执行结果是否产生完整 Trace / Audit / Report。
7. 资源是否可以 Reference / Clone / Fork。
8. V1.0 固有流程是否能够被 V2.0 Capability 抽象和复用。
