# Project Weekly Intelligence V1.2

## KPI 周报

每个 Project 单独配置 KPI、Target、口径、数据来源和周期。系统每周定时读取用户填写/确认的数据并自动生成 KPI 周报。

### 数据来源明细

每个 KPI 值至少记录：

- Project
- KPI
- Value / Unit
- Definition
- Target
- Source
- Source Detail
- Time Range
- Collection / Input Time
- Data Version / Batch（适用时）
- User Provided / System Collected
- Evidence Reference

### 周报

报告至少包含：

- 本周实际值
- KPI 目标
- 差值
- 达成率
- 环比/趋势（有足够历史数据时）
- 数据质量问题
- 来源明细
- 结论与建议

## 竞品周报

每个 Project 独立配置竞品清单、关注维度和来源。每周自动收集、去重、归并和对比，生成项目竞品周报。

每条关键结论记录：

- 竞品
- 事件/主题
- 发布时间
- 采集时间
- 来源
- 原始链接/证据
- 事实/分析判断
- 不确定性

## 可靠性

缺失数据、来源异常、口径冲突或无法验证的信息必须显式标记。禁止猜测、补造或将分析判断包装成事实。

## Project Isolation

不同 Project 的 KPI、竞品清单、来源、报告和历史数据必须隔离，不能混用。
