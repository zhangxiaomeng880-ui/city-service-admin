# REQ-001 UI Checklist

本文件用于 Engineering 前的视觉验收，不替代最终设计稿。

## 左侧一级分类

- 操作入口与分类名称保持明确的从属关系
- 不增加明显表格化分割线
- 操作入口默认弱化，交互时清晰可见
- 删除采用危险操作语义
- 当前选中分类状态保持稳定

## 编辑

- 分类名称输入框清晰
- 保存/取消层级明确
- 空值状态有明确反馈
- 保存中避免重复提交

## 删除

- 二次确认明确表达删除对象和影响
- 有关联服务时禁止删除
- 禁止删除提示解释原因，而非只展示错误
- 删除提交中避免重复操作

## 列表刷新

- 删除成功后左侧列表立即反映结果
- 当前选中项被删除后右侧内容不会残留旧数据
- 前台联动符合既定发布机制
