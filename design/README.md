# Design

记录 AI Native 产品流程中的信息架构、UX、UI 和原型资产。

- `ux/` 信息架构与交互
- `ui/` 视觉设计
- `prototype/` 可运行原型与设计验证

设计输出必须能够追溯到已确认的产品需求，并为 Engineering 提供明确的实现依据。

## 当前设计资产

- `ux/REQ-001-design.md`：一级分类编辑与删除的交互规格
- `ui/REQ-001-ui-checklist.md`：Engineering 前的视觉验收清单

## 设计阶段原则

Design 阶段先确定信息架构、交互状态和异常路径，再进入具体视觉实现。若缺少真实现有页面，应将视觉细节标记为待基于现有实现确认，而不是擅自发明页面结构。
